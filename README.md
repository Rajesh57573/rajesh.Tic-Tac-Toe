# 🎮 Tic-Tac-Toe Game

A modern, responsive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. Enjoy a classic two-player game with a stylish dark UI, smooth animations, and an interactive winning effect.


## 🌐 Live Demo

**Play here:** [Add your deployed website link here](https://rajeshtic-tac-toe.vercel.app/)

## ✨ Features

- 🎨 Modern dark-themed UI with gradient effects
- ❌ Two-player gameplay (Player 1: O, Player 2: X)
- 🏆 Automatic winner detection
- 💚 Animated winning cells
- 🔄 Reset Game and New Game buttons
- 📱 Responsive design for mobile, tablet, and desktop
- ⚡ Smooth hover and transition effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Play

1. Open the game in your browser.
2. Player 1 plays as **O**.
3. Player 2 plays as **X**.
4. Match three symbols horizontally, vertically, or diagonally to win.
5. Click **Reset Game** or **New Game** to play again.
